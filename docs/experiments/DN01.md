# DN01: dense baseline

## Question

How good is a tiny dense model on this domain, and what does every later
number compare against?

## Change from the previous experiment

The first model: one transformer block with a single feed-forward network.

## Configuration

Embedding width 16, hidden width 32, one head, causal attention with a
residual, RMS norm, an LM head; window 28; 120 examples; 300 epochs; Adam
at learning rate 0.003; masked cross-entropy over answer and stop tokens;
per-example training with no cross-example attention. About 16 seconds on
a laptop, deterministic, so diagrams and the results row are checked in
the gate.

## What we learned

At 120 examples the model memorizes: training loss keeps falling while
validation loss bottoms out and rises. Only prose generalizes. This is the
baseline for [finding 1](../results/current-findings.md).

## What we did not prove

That the dense model is capacity-limited; DS01 shows it is data-limited.
